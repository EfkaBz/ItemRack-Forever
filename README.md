## English

ItemRack Forever is ItemRack, adapted to World of Warcraft: Forever. Save your gear as sets, swap them in one click or one key, and let the addon change your gear for you when something happens.

### Features

- **Equipment sets:** save any combination of gear with a name and an icon, then equip it from the menu, a key binding or a macro.
- **Quick-swap buttons:** put any equipment slot on screen and pick another item from a menu when you hover it.
- **Auto queues:** trinkets and other usable items swap themselves when their cooldown starts.
- **Events:** equip a set when you mount, swim, enter a zone, change stance or form, gain a buff, or with your own scripts.
- **Dual specialization:** a set can switch your talent specialization when you equip it.
- **Baganator support:** your sets show in your bags, with the items each set contains.
- **Native interface:** the look of the original ItemRack and of the game.
- **Two languages:** English and French.

### Installation

Copy the `ItemRack_Forever` folder into `Interface\AddOns`, then restart the game.

### Commands

| Command | What it does |
|---|---|
| `/itemrack` | Open the options window |
| `/itemrack sets` / `events` / `queue` | Open the options on that tab |
| `/itemrack equip <set>` | Equip a set |
| `/itemrack unequip <set>` | Take off a set |
| `/itemrack toggle <set>[, <set>]` | Swap between one or two sets |
| `/itemrack spec 1` / `spec 2` | Switch specialization |
| `/itemrack lock` / `unlock` | Lock or unlock the buttons |
| `/itemrack reset` | Reset the buttons |
| `/itemrack reset everything` | Reset all settings and sets |

## Français

ItemRack Forever est ItemRack, adapté à World of Warcraft: Forever. Enregistrez votre équipement en ensembles, changez-en d'un clic ou d'une touche, et laissez l'addon changer votre équipement quand quelque chose se passe.

### Fonctionnalités

- **Ensembles d'équipement :** enregistrez n'importe quelle combinaison d'objets avec un nom et une icône, puis équipez-la depuis le menu, un raccourci ou une macro.
- **Boutons d'échange rapide :** placez n'importe quel emplacement d'équipement à l'écran et choisissez un autre objet dans un menu au survol.
- **Files automatiques :** les bijoux et autres objets utilisables s'échangent tout seuls quand leur temps de recharge commence.
- **Événements :** équipez un ensemble en montant à cheval, en nageant, en entrant dans une zone, en changeant de posture ou de forme, en gagnant une amélioration, ou avec vos propres scripts.
- **Double spécialisation :** un ensemble peut changer votre spécialisation de talents quand vous l'équipez.
- **Compatible Baganator :** vos ensembles s'affichent dans vos sacs, avec les objets de chaque ensemble.
- **Interface native :** le look de l'ItemRack d'origine et du jeu.
- **Deux langues :** anglais et français.

### Installation

Copiez le dossier `ItemRack_Forever` dans `Interface\AddOns`, puis relancez le jeu.

### Commandes

| Commande | Effet |
|---|---|
| `/itemrack` | Ouvre la fenêtre d'options |
| `/itemrack sets` / `events` / `queue` | Ouvre les options sur cet onglet |
| `/itemrack equip <ensemble>` | Équipe un ensemble |
| `/itemrack unequip <ensemble>` | Retire un ensemble |
| `/itemrack toggle <ensemble>[, <ensemble>]` | Alterne entre un ou deux ensembles |
| `/itemrack spec 1` / `spec 2` | Change de spécialisation |
| `/itemrack lock` / `unlock` | Verrouille ou déverrouille les boutons |
| `/itemrack reset` | Réinitialise les boutons |
| `/itemrack reset everything` | Réinitialise tous les réglages et ensembles |
